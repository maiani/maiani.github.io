Personal academic website for Andrea Maiani, built with Hugo and the Toha theme.

The blog separates outreach (`content/posts/research_post/`) from research notes
and discussions (`content/posts/technical/`). Posts use page bundles; Italian translations
live alongside their English versions as `index.it.md`, sharing the bundle's images.
The outreach folder keeps its existing name to preserve published URLs.
Blog section indexes set `showSectionIntro: true` to show their title and introduction;
this opt-in feature is implemented in the local Toha fork's list template.
